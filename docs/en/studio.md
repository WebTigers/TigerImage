# Using the studio

An image is never right the first time. The studio's whole job is to make the second, third and tenth
attempt cheap.

## Generate

Describe the image, optionally say what to **avoid**, choose a shape and how many, and generate. Asking
for several at once is usually the faster route: comparing four is more useful than judging one.

## Refine, rather than retype

Every tile has **Refine**. It reuses the original's parameters and lets you change only what you want, so
"the same but warmer" is a small edit rather than a re-typed prompt. The result is linked to what it came
from, and **Details** shows the chain — so a run of attempts stays navigable instead of becoming a pile
of similar pictures.

**Details** also shows exactly how an image was made: provider, model, size, and the parameters used.

## Keep or bin

- **Keep** promotes the image into the **Media Library**, where it becomes an ordinary media item you can
  use anywhere. Write the **alt text** first — you are the person who just looked at the image, and so
  the person best placed to describe it.
- **Bin** removes it from storage. Refinements made *from* it are kept and re-attached to its parent, so
  binning a rough draft never destroys the good image that came out of it.

Binning is not a refund: the money was already spent with the provider, so a binned image still counts
against your budget. Otherwise a runaway loop could reset its own budget by discarding as it went.
