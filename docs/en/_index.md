# TigerImage

Image generation for any agent. Describe a picture, compare what comes back, keep the one you want —
and because every image remembers how it was made, "the same but warmer" is a tweak rather than a
retype.

It adds **no new AI account**. It drives the provider adapters your site already has, so an install
configured for OpenAI generates with OpenAI.

- **[Setting it up](/docs/tigerimage/setup)** — pick a provider, add a key, turn it on.
- **[Using the studio](/docs/tigerimage/studio)** — generate, refine, keep, bin.
- **[Budgets](/docs/tigerimage/budget)** — the spend ceiling, and the gauge that shows it.
